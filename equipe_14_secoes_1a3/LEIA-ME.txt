======================================================================
3. PRÉ-REQUISITOS
======================================================================
  a) Python instalado. Para conferir, num terminal:
         python --version
     No Windows, se aparecer "Python was not found", o Python não está no PATH.
     Use o caminho completo do executável. Se o Python foi instalado com o uv, por exemplo:
         C:\Users\<usuario>\.local\bin\python3.15.exe --version
     Nesse caso, troque "python" por esse caminho no passo 5a abaixo.

  b) A base descompactada. A pasta raiz é a que contém Datasets\ e Scripts\, por exemplo:
         ...\Embedded_WiFi_Sensing-main\Datasets\Activity\FA\s1\csi_data_1720464506.txt
     Atenção: o ZIP original cria uma pasta dentro de outra
     (Embedded_WiFi_Sensing-main\Embedded_WiFi_Sensing-main). Use a mais interna, a que tem Datasets\.

======================================================================
4. CONFIGURAÇÃO (arquivo config.py)
======================================================================
  Abra config.py num editor de texto e ajuste as duas linhas abaixo:

    RAIZ_BASE = Path(os.environ.get(
        "RAIZ_BASE_CSI",
        r"C:\caminho\para\Embedded_WiFi_Sensing-main"))    <- caminho da pasta raiz da base

    ID_EQUIPE = 14                                          <- ID da equipe (tabela 2.2 do enunciado)

  Os participantes são escolhidos automaticamente pelo ID (14 -> s19, s21, s22),
  conforme a tabela PARTICIPANTES_POR_EQUIPE do próprio config.py.

  Alternativa sem editar o arquivo: defina a variável de ambiente RAIZ_BASE_CSI antes de executar.
      PowerShell:  $env:RAIZ_BASE_CSI = "C:\caminho\para\Embedded_WiFi_Sensing-main"
      cmd:         set RAIZ_BASE_CSI=C:\caminho\para\Embedded_WiFi_Sensing-main
      Linux/macOS: export RAIZ_BASE_CSI=/caminho/para/Embedded_WiFi_Sensing-main

======================================================================
5. PASSO A PASSO DE EXECUÇÃO
======================================================================
  Abra um terminal (PowerShell, cmd ou terminal do VS Code) DENTRO desta pasta.
  No VS Code: menu Terminal > Novo Terminal. No Explorador de Arquivos: clique com o botão direito
  na pasta > "Abrir no Terminal".

  a) Criar um ambiente virtual (uma única vez):
         python -m venv .venv

  b) Instalar as bibliotecas (uma única vez):
         Windows:      .venv\Scripts\python.exe -m pip install -r requirements.txt
         Linux/macOS:  .venv/bin/python -m pip install -r requirements.txt

  c) Executar as seções 1, 2 e 3 (cerca de 30 a 60 segundos):
         Windows:      .venv\Scripts\python.exe executar_secoes_1a3.py
         Linux/macOS:  .venv/bin/python executar_secoes_1a3.py

     Ao final, o programa mostra a conferência dos entregáveis. Todos devem aparecer como [OK]:
         [OK] inventario_gravacoes.csv com 1647 linhas de dados
         [OK] contagem_gravacoes.csv com 22 participantes + linha Total
         [OK] selecao_30_gravacoes.csv com 30 linhas de dados
         [OK] verificacao_amplitude.txt gerado
         [OK] 5 painéis da seção 3 (30 gráficos)

  d) (Opcional) Gerar o relatorio.pdf a partir do relatorio.md:
         .venv\Scripts\python.exe -m pip install markdown
         .venv\Scripts\python.exe gerar_relatorio_pdf.py
     Esse passo também cria o relatorio.html. Se o Edge ou o Chrome não for encontrado, abra o
     relatorio.html no navegador e use Imprimir > Salvar como PDF.

  Alternativa ao passo (c): executar uma seção por vez, NESTA ORDEM (cada uma usa o CSV da anterior):
         .venv\Scripts\python.exe secao1_inventario.py
         .venv\Scripts\python.exe secao2_selecao.py
         .venv\Scripts\python.exe secao3_amplitudes.py
     A seção 1 aceita o caminho da base como argumento, o que dispensa editar o config.py:
         .venv\Scripts\python.exe secao1_inventario.py "C:\caminho\para\Embedded_WiFi_Sensing-main"
     (as seções 2 e 3 continuam usando RAIZ_BASE ou RAIZ_BASE_CSI)

  Com ambiente ativado (opcional): .venv\Scripts\activate (Windows) ou source .venv/bin/activate
  (Linux/macOS). Depois disso, basta digitar "python executar_secoes_1a3.py".
  No PowerShell, se a ativação for bloqueada, rode antes:
         Set-ExecutionPolicy -Scope Process Bypass

======================================================================
6. PROBLEMAS COMUNS
======================================================================
  "Base não encontrada em ..."       RAIZ_BASE aponta para a pasta errada (ver itens 3b e 4).
  "No module named numpy"            o passo 5b não foi feito, ou o comando usou um python
                                     diferente do .venv. Use .venv\Scripts\python.exe.
  "FileNotFoundError ... selecao_30_gravacoes.csv"
                                     a seção 3 foi executada antes da 2. Siga a ordem 1 -> 2 -> 3.
  Acentos estranhos no terminal do Windows:
                                     antes de executar, rode $env:PYTHONIOENCODING="utf-8" (PowerShell).
                                     Os arquivos gerados são UTF-8 e não são afetados.
